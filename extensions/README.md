# EAOS Extension Framework Package (`extensions/`)

## Business Capability
Extensible Plugin Architecture, SaaS Connectors, Runtime Hardware Drivers, Dynamic Plugin Discovery, and Hot-Plugging Engine.

## Package Structure
- `connectors/`: External SaaS & Protocol Connectors (`base_connector.py`).
- `drivers/`: Hardware & Infrastructure Drivers (`base_driver.py`).
- `plugins/`: Dynamic Plugin Discovery & Registry (`plugin_manager.py`).
- `extension_registry.py`: Master Extensions Registry Engine.
