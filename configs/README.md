# EAOS Environment Configurations Package (`configs/`)

## Business Capability
Declarative Environment Configuration Management, Policy Manifests, and Multi-Tier Deployment Settings.

## Sub-Environments Architecture
- `airgapped/`: Disconnected offline deployment settings.
- `development/`: Local development settings.
- `staging/`: Staging verification settings.
- `production/`: Production 24/7 hardened settings and telemetry.
- `testing/`: Isolated unit/integration test settings.
