# EAOS Site Reliability Engineering & Operations Package (`operations/`)

## Business Capability
Site Reliability Engineering (SRE), Incident Response (P1-P4), FinOps Cost Tracking, Executable YAML Runbooks, Operational Governance, and Observability Metrics.

## Package Structure
- `sre/`: SRE Availability & Error Budget Engine (`sre_engine.py`).
- `incident/`: Incident Response P1-P4 Management (`incident_response.py`).
- `finops/`: FinOps Cost Tracking & Resource Metering (`finops_cost_tracker.py`).
- `runbooks/`: Executable YAML Runbooks Orchestrator (`runbook_executor.py`).
- `capabilities/`: Operations Capabilities (`backup`, `incident`, `monitoring`, `recovery`).
- `governance/`: Operational Governance Policies & Workflows.
- `sre_runbook.py`: Master SRE Operations Engine.
