# EAOS Executable Examples Suite Package (`examples/`)

## Business Capability
Executable Starter Code Examples for Developers and AI Agents demonstrating EAOS Kernel initialization, Knowledge RAG, Policy Evaluation, Business Capability Services, and Multi-Agent Swarm Workflows.

## Package Structure
- `hello_eaos/`: Hello EAOS starter example (`hello_world.py`).
- `knowledge/`: Knowledge Graph & Vector RAG example (`knowledge_example.py`).
- `policy/`: OPA Rego Policy evaluation example (`policy_example.py`).
- `services/`: Business Capability Service execution example (`service_example.py`).
- `workflow/`: 5-Agent Swarm Workflow execution example (`workflow_example.py`).
- `runner.py`: Master Executable Examples Runner.
