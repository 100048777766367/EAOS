# EAOS Enterprise Digital Twin Package (`digitaltwin/`)

## Business Capability
Enterprise Digital Twin, What-If Change Simulation, Event Replay, Risk Modeling, and Pre-Deployment Impact Analysis.

## Package Structure
- `models/`: Digital Twin State DTOs (`twin_models.py`).
- `simulation/`: What-If Change Simulation Engine (`twin_simulation.py`).
- `replay/`: Event Trace Replay Engine (`twin_replay.py`).
- `twin_orchestrator.py`: Master Digital Twin Orchestrator.
