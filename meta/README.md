# EAOS Enterprise Meta-System Package (`meta/`)

## Business Capability
Enterprise Meta-System, Universal Metamodels, Domain Taxonomies, Meta-Ontologies, and Security Data Classification.

## Package Structure
- `metamodel/`: Universal Enterprise Metamodel Engine (`metamodel_engine.py`).
- `taxonomy/`: Enterprise Taxonomies & Domain Hierarchies (`taxonomy_engine.py`).
- `ontology/`: Meta-Ontology Alignment.
- `classification/`: Security & Sensitivity Classification Engine (`classification_engine.py`).
- `enterprise_meta_system.py`: Master Enterprise Meta-System Orchestrator.
