# EAOS Enterprise Knowledge Base Package (`knowledge/`)

## Business Capability
Single Source of Truth Knowledge Repository, Evidence Ledger Auditing, Immutable Core Axioms, W3C JSON-LD Enterprise Ontologies, Ubiquitous Language Glossary, and Architectural Specifications.

## Package Structure
- `axioms/`: Core & Immutable Axioms Verifier (`axiom_verifier.py`).
- `evidence/`: Cryptographic Evidence Ledger Auditor (`evidence_ledger.py`).
- `glossary/`: Ubiquitous Language & Domain Glossary (`ubiquitous_language.md`).
- `metamodels/`: EAOS Enterprise Metamodels (`eaos_metamodel.json`).
- `ontologies/`: W3C JSON-LD Enterprise Ontology (`enterprise_ontology.jsonld`).
- `specifications/`: Executable YAML Specifications.
- `knowledge_base_engine.py`: Master Knowledge Base Engine.
