# EAOS Core Execution & Cybernetic Engine (`engine/`)

## Business Capability
Master Execution Engine providing closed cybernetic feedback loops, capability runtime, WASM sandboxing, specification parsing, architecture compilation, and automated fitness auditing.

## 12 Sub-Engines Architecture
1. **`capability/`** — Capability Runtime, Command Bus & Hot Lifecycle.
2. **`compiler/`** — Architecture Compiler & Policy Code Compiler.
3. **`executor/`** — Task Executor Engine.
4. **`generator/`** — Multi-Target Code Generator Engine.
5. **`governance/`** — Topology Auditor & Fitness Functions Engine.
6. **`indexer/`** — Knowledge Indexer & Semantic RAG Search.
7. **`loader/`** — Capability Hot Loader.
8. **`parser/`** — Specification Parser (YAML/DSL v1).
9. **`planner/`** — Autonomous Task Planner & Scheduler.
10. **`sandbox/`** — WASM Runtime Sandbox for Isolated Execution.
11. **`scheduler/`** — Closed Cybernetic Feedback Loop Scheduler.
12. **`validator/`** — Specification & Rule Validator Engine.
13. **`workflow/`** — State Machine Workflow Engine.
