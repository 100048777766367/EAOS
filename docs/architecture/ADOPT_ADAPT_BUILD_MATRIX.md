# EAOS Tech Stack Strategy: Adopt -> Adapt -> Build Matrix

EAOS strictly adheres to Constitutional Rule R8 (Adopt -> Adapt -> Build)
and Principle P12 (Ecosystem Before Reinvention).

## 1. ADOPT (Commodity Infrastructure - Used As-Is)
FastAPI, Typer, Pydantic, PostgreSQL, Redis, MinIO, Prometheus, Grafana,
OpenTelemetry, Ruff, MyPy, Pytest.

## 2. ADAPT (Ecosystem Extensions - Integrated via Ports & Adapters)
Neo4j, Qdrant, OPA, Keycloak, Temporal, Kafka, NATS.

## 3. BUILD (EAOS Proprietary Unique Core)
1. Architecture Engine
2. Rule Toolkit (RTK)
3. Capability Engine
4. Architecture Knowledge Graph
5. Governance Engine
6. Architecture Fitness Engine
7. Enterprise Memory
8. AI Orchestrator
9. EAOS Dashboard UI
