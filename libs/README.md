# EAOS Shared Enterprise Libraries Package (`libs/`)

## Business Capability
Shared Core Primitives, Result DTOs, Schema Validation Helpers, Cryptographic Hash Evidence Utilities, and Reusable Domain Primitives.

## Package Structure
- `core/`: Shared Core Primitives (`domain.py`, `shared_primitives.py`).
- `validation/`: Schema Validation Helpers (`checker.py`, `schema_validator.py`).
- `crypto/`: Cryptographic & Hash Evidence Helpers (`security_utils.py`).
- `libs_orchestrator.py`: Master Shared Libraries Engine.
