Quản trị toàn bộ danh mục 80+ Năng lực Kinh doanh Doanh nghiệp (BIZBOK v12),
xác thực bộ 7 tệp đặc tả chuẩn (API, Capability, Domain, Tasks, Tests, UI, Workflow)
