# EAOS Enterprise Operating Model Package (`operatingmodel/`)

## Business Capability
Enterprise Operating Model (OMC / BIZBOK / APQC PCF), Value Stream Mapping, Organizational Structure, Business Process Architecture, Operating Role RACI Matrix, and Operating Services Catalog.

## Package Structure
- `value_streams/`: Value Stream Mapping Engine (`value_stream_engine.py`).
- `organization/`: Business Units & Org Structure (`organization_engine.py`).
- `processes/`: APQC PCF / BPMN Process Architecture (`process_architecture.py`).
- `roles/`: Operating Roles & RACI Matrix (`role_matrix.py`).
- `services/`: Business Operating Services Catalog (`operating_service.py`).
- `model_registry.py`: Master Operating Model Registry Engine.
