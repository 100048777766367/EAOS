# EAOS Capability & Agent Marketplace Package (`marketplace/`)

## Business Capability
Enterprise Capability Pack Publishing, Agent Swarm Pack Installer, OPA Policy Pack Marketplace, Executable Workflow Packs, and Versioned Pack Registry.

## Package Structure
- `capability_pack/`: Capability Pack Installer (`capability_pack_installer.py`).
- `agent_pack/`: Agent Swarm Pack Installer (`agent_pack_installer.py`).
- `policy_pack/`: OPA Policy Pack Installer.
- `workflow_pack/`: Executable Workflow Pack Installer.
- `pack_registry.py`: Master Pack Registry Engine.
