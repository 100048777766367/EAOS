# EAOS Organizational Memory Package (`memory/`)

## Business Capability
Organizational Memory, Architectural Decision Records Memory, Operational Incident History, Hybrid Vector Memory (Qdrant), and Splay RWLock Cache.

## Package Structure
- `architectural/`: Architectural Decision Memory (`architectural_memory.py`).
- `operational/`: Operational Incident Memory (`operational_memory.py`).
- `organizational/`: Organizational Intelligence.
- `vector/`: Hybrid Vector RAG Memory Engine (`vector_memory.py`).
- `enterprise_memory.py`: Master Enterprise Memory Orchestrator.
