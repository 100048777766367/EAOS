# EAOS Enterprise Decision Engine Package (`decisions/`)

## Business Capability
DMN-Compliant Decision Tables Evaluation, Business & Architectural Rules Engine, Scenario Decision Planning, and Utility/FinOps Optimization.

## Package Structure
- `rules/`: Deterministic Rule Evaluators (`rule_evaluator.py`).
- `evaluation/`: DMN Decision Table Evaluator (`decision_table_evaluator.py`).
- `planning/`: Strategic Scenario Decision Planner (`scenario_decision_planner.py`).
- `optimization/`: Decision Utility & FinOps Optimizer (`decision_optimizer.py`).
- `decision_engine.py`: Master Enterprise Decision Engine.
